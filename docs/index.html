Under the hood

One command, built for you

The GUI assembles an auto_editor command from your inputs, runs it through the bundled Python module, and streams the result back.

Frequently asked questions

  

    
Do I need to install Python or auto-editor?
No. Python and auto-editor are bundled with the app, so end users never install them. Download the Windows installer and run it. It does not need admin rights.

    
Which editors can I export to?
Adobe Premiere Pro, DaVinci Resolve (FCP7 XML), Final Cut Pro and Shotcut timelines, plus a regular edited media file or multiple numbered clips.

    
Windows says “Windows protected your PC”. Is that expected?
The installer is not code-signed yet, so SmartScreen may show that warning. Click More info, then Run anyway.

    
Which systems are supported?
Windows 10 or 11, 64-bit. Developers can also run it from source with Node.js 18+ and Python 3.10+.

    
The preview says the format can’t be previewed.
Chromium can’t play every format, for example some .mkv and .avi files. You can still export them.

    
Where does it come from?
The GUI wraps auto-editor by Wyatt Blue and is built with Electron, React, TypeScript and Vite. See the repository’s LICENSE file for terms.
